# Moving to 0.4.4.1

The releases `0.4.4.2-beta1` and `0.4.4.3-beta1` were numbered incorrectly.
Their fixes are included in `0.4.4.1`, and the superseded beta releases are
being retired. Existing installations are not automatically renamed.

## If you installed either incorrectly numbered beta

HACS may consider `0.4.4.1` older and therefore not offer an automatic update.
Removing a beta release from GitHub does not change its installed version.

1. Wait for cleaning to finish and ensure no cleaning plan is active.
2. Create a Home Assistant backup.
3. Open HACS and select **Matic (Unofficial)**.
4. Open the repository menu and choose **Redownload**.
5. Select **v0.4.4.1** explicitly and download it. If it is missing, refresh
   repository information and reopen the version selector.
6. Restart Home Assistant.
7. Confirm HACS reports **v0.4.4.1**, the robot reconnects, and Matic Map shows
   the live map and verified robot position. Check that saved plans remain.

This is an intentional version-number correction, not a return to older robot
behavior. Do not uninstall the integration or remove its configuration entry.
Once the installed version is `0.4.4.1`, normal future version ordering resumes.

Users on `0.4.4` or `0.4.4.1-beta1` can use the normal HACS update flow.

## Validation limit

The equivalent beta passed automated checks, installed-file verification,
restart, live-map and idle-state checks. Controlled physical blocked-dock
acceptance remains unverified.
