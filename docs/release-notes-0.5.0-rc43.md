# v0.5.0-rc43

RC43 retains the [RC42 status and progress improvements](release-notes-0.5.0-rc42.md). When a landscape phone leaves only a shallow map visible, room names stay closer to their rooms and the current or selected rooms take priority. More names return as the map gains space.

This is a prerelease. Preserve a verified Home Assistant backup and the installed integration and configuration stores before updating; follow the [rollback guidance](verification-0.5-rc24.md). Installed and physical qualification remain separate from source tests and review.
