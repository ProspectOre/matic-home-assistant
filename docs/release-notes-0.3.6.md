# 0.3.6

Released: 2026-08-15

- Adds Matic Cues voice/gesture sensors, following-person state, and lifecycle events for automations.
- Labels the existing voice-enable switch **Matic Cues**.
- Extends automatic firmware checks with value-free field-shape comparisons. New fields appear in diagnostics; endpoint availability changes can create a Repair.

Before enabling or automating Cues, read
[Matic's voice-data handling](privacy.md#matic-cues).
