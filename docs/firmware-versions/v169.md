## Changes and capability candidates

- The robot briefly rejected one coordinator refresh while rebooting. It
  reconnected automatically, and the error did not repeat.
- Version metadata arrived before protocol/profile metadata. The integration now
  snapshots firmware and protocol as a pair so staged metadata cannot leave the
  compatibility result pending.
- No endpoint availability or transport regression was detected. Sixteen
  endpoint fingerprints changed content; raw payloads were not retained.
- A deliberately interrupted single-room task closed as incomplete. It did not
  change that room's last-cleaned timestamp, learned duration, or the completed-
  run total. This confirms that the post-OTA control path did not introduce
  false completion credit.
- The unified map workspace saved a bounded custom area on the authenticated
  photo layer, retained it across restart, dispatched it successfully, and
  observed the robot return to the dock. Home Assistant entered live-pose map
  mode as the robot began the local run; no map data or raw command payload was
  retained in this ledger.
- Separate standard-coverage runs completed in vacuum, mop, and
  vacuum-and-mop modes with verified native completion, correct per-room credit,
  and no persistent problem state. The combined run also crossed a firmware
  return/resume cycle without premature credit.
- A complete two-room saved plan transitioned directly between rooms without
  docking, credited exactly the two verified completions, and docked only after
  the final room.
- The intelligent stop policy was exercised below and above a 50% learned
  threshold. The below-threshold run stopped immediately without credit or a
  next-room start. The above-threshold run finished only the active room,
  credited it once, did not start the next room, and then docked.
- The Home Assistant log recorded no new Matic integration error during the
  control check. The only post-update Matic error remained the expected
  connection failure while the robot rebooted for the OTA.
- No new command or Home Assistant exposure is approved from this observation.
