# v0.5.0-rc42

RC42 retains the [RC41 Smart Stop and progress updates](release-notes-0.5.0-rc41.md). It fixes a progress-label error that could appear on a Home Assistant page left open during an update, and falls back to clear English if a translation cannot be formatted. The collapsed map panel now keeps the active room and Smart Stop explanation visible.

This is a prerelease. Preserve a verified Home Assistant backup and the installed integration and configuration stores before updating; follow the [rollback guidance](verification-0.5-rc24.md). Installed and physical qualification remain separate from source tests and review.
